# Riesgos y limitaciones

- El prototipo no implementa aprobación multinivel ni valorización contable.
- La evidencia se almacena como referencia; no existe repositorio de archivos.
- La disponibilidad depende de SQL Server; se recomienda respaldo y monitoreo.
- LocalDB es solo para desarrollo.
- Los informes grandes deben limitarse con filtros de período.
- La cuenta inicial depende de secretos externos y debe cambiarse.
- Docker Compose es una topología demostrativa, no alta disponibilidad.
