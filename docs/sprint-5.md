# Sprint 5 — calidad, seguridad, documentación y despliegue

- Sistema visual de Stitch aplicado a navegación, cabecera, tarjetas, filtros, estados y tablas.
- Dashboard dinámico por período con KPI, movimientos, alertas y mermas por motivo.
- Centro de auditoría autorizado para Administrador.
- Correlation ID en respuestas, logs, auditoría y página de error.
- Rate limiting del login, cookies seguras, CSP y cabeceras defensivas.
- Health checks de proceso y SQL Server.
- Configuración fuertemente tipada y archivo de producción sin secretos.
- Dockerfile, Docker Compose, scripts de migración/publicación y guías IIS/rollback.
- Manuales de instalación, usuario y administración; plan de pruebas y registro de riesgos.
